# Reporte Final Unificado

Este folder contiene el reporte final curado.

Archivos:

- `reporte_final.tex`: fuente LaTeX.
- `reporte_final.pdf`: PDF compilado.
- `figuras/`: solo las figuras importantes usadas por el reporte.

## Criterio

El reporte final no usa todas las graficas. Usa solo las que ayudan a contar la historia:

1. forma de las variables respuesta
2. patron de readmision por edad
3. relacion entre variables con Spearman
4. efectos del modelo logistico
5. diagnostico del modelo Gamma

Las demas graficas quedan en `../graficas/todas/`.
