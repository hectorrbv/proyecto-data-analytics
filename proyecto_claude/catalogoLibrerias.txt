## 1. `numpy` (importado como `np`)

Operaciones numéricas vectorizadas sobre arrays N-dimensionales.

| Función / Método | Uso |
|---|---|
| `np.array()` | Crear array desde lista |
| `np.zeros()` | Array de ceros |
| `np.arange()` | Secuencia entera |
| `np.linspace()` | Secuencia flotante uniforme |
| `np.concatenate()` | Unir arrays en un eje |
| `np.mean()` | Media aritmética |
| `np.median()` | Mediana |
| `np.std()` | Desviación estándar |
| `np.percentile()` | Percentil k de un array |
| `np.sqrt()` | Raíz cuadrada |
| `np.log()` / `np.log10()` | Logaritmo natural / base 10 |
| `np.exp()` | Función exponencial |
| `np.abs()` | Valor absoluto |
| `np.clip()` | Limitar valores en rango |
| `np.random.seed()` | Semilla de aleatoriedad |
| `np.random.default_rng()` | Generador moderno (`.normal()`, `.exponential()`, etc.) |
| `np.random.choice()` | Muestreo con/sin reemplazo |
| `np.random.rand()` | Uniforme [0,1) |
| `np.random.normal()` | Distribución normal |
| `np.random.lognormal()` | Distribución log-normal |
| `np.random.exponential()` | Distribución exponencial |
| `np.linalg.inv()` | Inversa de matriz |
| `np.cov()` | Matriz de covarianza |
| `np.isnan()` | Máscara booleana de NaN |
| `np.full_like()` | Array del mismo shape con valor constante |
| `np.histogram_bin_edges()` | Bordes de bins para histograma |
| `np.histogram()` | Histograma como conteos + bordes |
| `np.sum()` / `np.nanmax()` | Suma / máximo ignorando NaN |

### Ejemplos de código real

```python
# Generar datos sintéticos con el generador moderno
rng = np.random.default_rng(42)
N = 5000
raw = pd.DataFrame({
    'Exponential': rng.exponential(scale=2, size=N),
    'Gamma':       rng.gamma(shape=2.5, scale=2, size=N),
    'Lognormal':   rng.lognormal(mean=1.5, sigma=0.5, size=N),
})

# Aplicar transformación y calcular percentil
non_param_medians = np.zeros(10000)
for i in range(10000):
    sample = np.random.choice(tbf_data, size=len(tbf_data), replace=True)
    non_param_medians[i] = np.median(sample)

ci_lower = np.percentile(non_param_medians, 2.5)
ci_upper = np.percentile(non_param_medians, 97.5)

# Concatenar dos arrays (distribución bimodal)
bimodal = np.concatenate([rng.normal(0, 0.5, 5000), rng.normal(2.5, 1, 5000)])
```

## 10. `sklearn.preprocessing`

Transformadores de características.

| Clase | Uso |
|---|---|
| `StandardScaler` | Z-score: media=0, std=1 |
| `MinMaxScaler` | Escala al rango [0,1] |
| `RobustScaler` | Escala con mediana e IQR |
| `QuantileTransformer` | Mapea a distribución normal/uniforme |
| `PowerTransformer` | Box-Cox o Yeo-Johnson |
| `KBinsDiscretizer` | Discretización en bins |
| `OneHotEncoder` | Codificación one-hot |
| `LabelEncoder` | Codificación ordinal compacta |
| `OrdinalEncoder` | Codificación ordinal configurable |
| `PolynomialFeatures` | Features polinomiales |

### Ejemplos de código real

```python
# Box-Cox con sklearn
pt_box = PowerTransformer(method='box-cox')
x_box = pt_box.fit_transform(x.reshape(-1, 1)).flatten()

# Yeo-Johnson (soporta negativos)
pt_yeo = PowerTransformer(method='yeo-johnson')
x_yeo = pt_yeo.fit_transform(x.reshape(-1, 1)).flatten()

# Binning uniforme
binner = KBinsDiscretizer(n_bins=10, encode='ordinal', strategy='uniform')
x_bin = binner.fit_transform(x.reshape(-1, 1)).flatten()

# Binning por cuantiles
binner_q = KBinsDiscretizer(n_bins=8, encode='ordinal', strategy='quantile')
x_bin_q = binner_q.fit_transform(x.reshape(-1, 1)).flatten()
```

## 11. `sklearn.impute`

| Clase | Uso |
|---|---|
| `SimpleImputer` | Media, mediana, moda, constante |
| `KNNImputer` | Imputación por K vecinos más cercanos |
| `IterativeImputer` | MICE — imputación multivariada |

```python
# Media y mediana
imputer_mean   = SimpleImputer(strategy='mean')
imputer_median = SimpleImputer(strategy='median')
imputer_mode   = SimpleImputer(strategy='most_frequent')
df['col'] = imputer_mean.fit_transform(df[['col']])

# KNN con 2 vecinos
knn_imputer = KNNImputer(n_neighbors=2)
df[numerical_cols] = knn_imputer.fit_transform(df[numerical_cols])

# MICE (requiere enable_iterative_imputer)
from sklearn.experimental import enable_iterative_imputer
imp_mice = IterativeImputer(random_state=42)
df_mice = pd.DataFrame(imp_mice.fit_transform(df), columns=df.columns)
```
