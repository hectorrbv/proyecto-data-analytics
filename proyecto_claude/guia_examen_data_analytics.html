📊 GUÍA DE EXAMEN — Data Analytics 2: Inferencia y Probabilidad

Temas: Pruebas estadísticas · Distribuciones · Correlaciones · Multicolinealidad · Bootstrapping · LOF · EDA · eCDF

0 · Conceptos Base (los más básicos)

Población vs Muestra

  • Población (N): todos los elementos. Tiene parámetros constantes (µ, σ²) pero desconocidos
  • Muestra (n): subconjunto. Se describe con estadísticos (X̄, S²) que son variables aleatorias

H₀ vs Hₐ

  • H₀: no hay diferencia / no hay relación / todo es igual. Nunca se "acepta", solo se rechaza o no se rechaza
  • Hₐ: sí hay diferencia / hay relación
  • p < α: rechazar H₀ → evidencia de diferencia
  • p ≥ α: no hay evidencia suficiente para rechazar H₀

Ruido / Anomalía / Error

  • Ruido: variación aleatoria inherente a los datos, sin patrón
  • Anomalía (outlier): punto que se desvía significativamente del patrón general, puede ser real o un error
  • Error: dato incorrecto por medición, captura o proceso
⚠️ Error conceptual crítico: "Aceptamos H₀" es INCORRECTO. Lo correcto: "No hay evidencia estadística suficiente para rechazar H₀". El p-value NO es la probabilidad de que H₀ sea verdadera; es la probabilidad de ver datos tan extremos si H₀ fuera cierta.

2 · Distribuciones de Probabilidad

Distribución Tipo Variable que modela Cuándo elegirla — señales clave Parámetros E[X] / Var[X] Ejemplos en datos
Binomial Discreta Número de éxitos en n ensayos de Bernoulli n fijo, cada intento es éxito/fallo, independientes, p constante. Tiene techo: máximo n n (ensayos), p (prob éxito) np / np(1-p) Píxeles defectuosos en 500 sensores, clics en anuncio de 100 usuarios
Poisson Discreta Conteo de eventos en intervalo fijo de tiempo/espacio Eventos raros, independientes, sin techo natural. E[X] = Var[X] = λ λ (tasa promedio) λ / λ Fraudes por hora, peticiones a API por minuto, errores de servidor por día
Normal (Gaussiana) Continua Variables simétricas, distribución de errores Datos simétricos, campana, sin cola extrema. Errores de medición. Muchos procesos por TCL µ (media), σ² (varianza) µ / σ² Errores de regresión lineal, alturas de personas, temperaturas
Exponencial Continua Tiempo entre eventos en proceso Poisson Variable continua ≥ 0, propiedad sin memoria: P(esperar + t | ya esperé s) = P(esperar t). Cola a la derecha λ (tasa) 1/λ / 1/λ² Tiempo hasta 1ª caída del servidor, tiempo entre transacciones fraudulentas
Gamma Continua Tiempo hasta que ocurran α eventos Generalización de la exponencial. Cola derecha más flexible. Suma de exponenciales α (forma/shape), λ (tasa) α/λ / α/λ² Tiempo de resolución de tickets, carga total en servidores, montos de reclamos de seguros
Log-Normal Continua Variables con sesgo positivo extremo Datos siempre positivos + cola derecha muy larga (mayoría pequeños, pocos enormes). Si ln(X) ~ Normal, entonces X ~ Lognormal µ, σ (de ln(X)) exp(µ+σ²/2) / — Ingresos/salarios, tiempos de latencia con picos, precios de activos
Uniforme Continua Fenómenos donde todos los valores en [a,b] son igualmente probables Sin preferencia por ningún valor, todos equiprobables en un rango a (mín), b (máx) (a+b)/2 / (b-a)²/12 Número aleatorio generado por computadora, ángulo de llegada de partícula
Regla de oro para elegir distribución: ¿Los datos pueden ser negativos? → Normal/Uniforme. ¿Son conteos enteros? → Binomial (techo) o Poisson (sin techo). ¿Son tiempos de espera? → Exponencial (1 evento) o Gamma (k eventos). ¿Son valores positivos con cola enorme a la derecha? → Lognormal.
Binomial vs Poisson: Binomial tiene límite (n ensayos máx). Poisson no tiene techo. Cuando n es muy grande y p muy pequeño, Binomial ≈ Poisson con λ = np.
Exponencial vs Gamma: Exponencial = tiempo hasta 1 evento. Gamma = tiempo hasta α eventos (suma de α exponenciales independientes).
Binomial: P(X=k) = C(n,k)·p^k·(1-p)^(n-k) | Poisson: P(X=k) = (λ^k · e^{-λ}) / k! Lognormal: Mediana = e^µ (parámetro de tendencia central, no la media — ésta se infla por outliers)

3 · Correlaciones — Pearson vs Spearman vs Kendall

Coeficiente Mide Supuestos necesarios Escala de datos Empates Cuándo usarlo Cuándo NO usarlo
Pearson (r) Asociación lineal entre dos variables continuas Normalidad bivariada, relación lineal, sin outliers extremos, escala de intervalo/razón Continua, intervalos iguales Los ignora (asume continuidad) Altura vs Peso, temperatura vs ventas de helado (relación lineal clara) Datos ordinales (estrellas 1-5), relación curva, muchos empates, outliers extremos
Spearman (ρ) Asociación monótona (no necesariamente lineal) Solo relación monótona (si X sube, Y sube o siempre baja). Trabaja con rangos Ordinal o continua Asigna rangos promedio → con miles de empates se distorsiona Relación no lineal pero monótona, datos ordinales, outliers presentes Miles de empates (prefiere Kendall), datos con reversiones complejas
Kendall (τ) Probabilidad de concordancia entre pares: τ = P(concordante) − P(discordante) Solo relación monótona. Más robusto a empates que Spearman Ordinal o continua Penaliza empates directamente en el denominador → más estable Muchos empates (ej: calificaciones 1-5), datos ordinales con pocos valores únicos, EDA exploratorio Cuando se necesita comparabilidad con literatura que usa Pearson/Spearman
τ_b = (C - D) / √[(C+D+E_X)(C+D+E_Y)] donde C=concordantes, D=discordantes, E_X=empates en X, E_Y=empates en Y
Pearson con datos ordinales/empates = ERROR técnico: (1) Viola supuesto de linealidad si la relación es curva. (2) Viola supuesto de escala de intervalo: la distancia entre 3 y 4 estrellas no es necesariamente igual a entre 1 y 2. (3) Miles de empates en "4" comprimen la varianza artificialmente.

4 · Multicolinealidad — VIF

¿Qué es y por qué importa?

Cuando una variable predictora X₁ puede ser predicha casi perfectamente por otras variables (X₂, X₃), la matriz X'X se vuelve casi singular (det → 0). Consecuencias:

  • Los coeficientes β̂ son inestables: pequeños cambios en datos voltean signos
  • Los errores estándar de β̂ se inflan → t-tests no significativos aunque la variable sí importe
  • La fórmula β̂ = (X'X)⁻¹X'y falla porque la inversa es numéricamente inestable
VIF_i = 1 / (1 - R²_i)

donde R²_i es el R² de la regresión auxiliar de X_i contra todas las demás predictoras.

Ej: R² = 0.94 → VIF = 1/(1-0.94) = 1/0.06 ≈ 16.67 ⚠️ SEVERO

Umbrales y decisiones

VIFDiagnósticoAcción
1 – 5✅ NormalSin problema
5 – 10⚠️ ModeradoInvestigar, monitorear
> 10❌ SeveroActuar

Opciones cuando VIF > 10:

  • Eliminar la variable: si R²_i es alto, la variable ya está contenida en las demás y no agrega información nueva
  • PCA: crear componentes ortogonales que no correlacionen entre sí
  • Ridge (L2): regularización que estabiliza coeficientes sin eliminar variables

5 · Bootstrapping

No Paramétrico (remuestreo directo)

Cuándo: n pequeño, outliers, distribución desconocida, no puedes asumir normalidad.

  1. Tomar muestra de tamaño n de S con reemplazo
  2. Calcular estadístico de interés (ej: mediana)
  3. Repetir B = 10,000 veces
  4. IC 95% = percentiles 2.5 y 97.5 de las B medianas

✅ Ventaja No asume ninguna distribución, trabaja con datos reales
⚠️ Desventaja Solo puede generar valores dentro del rango original

Paramétrico (Monte Carlo)

Cuándo: Tienes justificación teórica para asumir una distribución (ej: Lognormal).

  1. Ajustar distribución: estimar µ̂, σ̂ de los datos
  2. Generar B muestras de tamaño n desde esa distribución
  3. Calcular estadístico en cada muestra
  4. IC 95% = percentiles 2.5 y 97.5

✅ Ventaja Genera valores fuera del rango observado, eficiente con n muy pequeño
❌ Desventaja Si el modelo asumido es incorrecto, todo el resultado está sesgado

¿Por qué SE clásico = s/√n falla con outliers? Con S = [2, 3, 2.5, 4, 3.1, 120]: la media = 22.4 no representa nada real, la varianza explota por 120 al cuadrado, y el IC clásico puede producir límites negativos (tiempo negativo = imposible físicamente). Con n=6 el Teorema Central del Límite no aplica.
IC 95% bootstrap = [percentil_2.5(medianas_boot), percentil_97.5(medianas_boot)] Bootstrap paramétrico (Lognormal): µ_log = mean(log(S)), σ_log = std(log(S)) → muestrear de lognormal(µ_log, σ_log)

6 · eCDF — Función de Distribución Empírica Acumulada

¿Qué es?

El eCDF es la fracción de datos que son ≤ a un valor x. Es completamente empírico: no asume ninguna distribución. Se construye ordenando los datos y asignando probabilidades acumuladas.

F̂(x) = (número de observaciones ≤ x) / n

Cómo leerlo para decisiones de negocio:

  • SLA ≤ 24h al 80%: localizar x=24 en eje X → subir hasta curva → leer F̂(24). Si F̂(24) ≥ 0.80: cumple ✅
  • P(ticket > 40h): leer F̂(40) → calcular 1 - F̂(40)

Regla complemento:

P(X > t) = 1 - F̂(t)

¿Por qué no usar Normal para tiempos?

  • Límite físico: Normal tiene soporte (−∞, +∞) → asigna probabilidad a tiempos negativos. Imposible.
  • Asimetría: histogramas de tiempos muestran pico izquierdo + cola larga derecha. Normal es simétrica.
  • Q-Q Plot: puntos se desvían de la línea en las colas → confirma no-normalidad

Familia correcta para tiempos de espera:

Gamma, Lognormal, Weibull, Exponencial. Soporte en [0, ∞), cola derecha larga.

7 · LOF — Detección de Anomalías por Densidad

LOF detecta outliers comparando la densidad local de un punto con la de sus vecinos. Un punto es anómalo si su densidad es mucho menor que la de sus vecinos (está en una zona poco poblada comparado con su entorno).

PasoConceptoDefinición
1 Distancia-k (k-distance) Distancia del punto p a su k-ésimo vecino más cercano. Define el "radio de búsqueda"
2 Distancia de alcance (reach-distance) max(k-distance(vecino), distancia real a vecino). Suaviza distancias muy pequeñas para evitar inestabilidad numérica
3 Densidad de alcance local (LRD) Inversa del promedio de reach-distances del punto p a sus k vecinos. Alta LRD = zona densa. Baja LRD = zona dispersa
4 LOF Score Promedio de (LRD_vecino / LRD_p) para los k vecinos. LOF ≈ 1: punto normal. LOF >> 1: anomalía (su zona es menos densa que sus vecinos)
Cuándo usar LOF: Cuando los outliers dependen del contexto local (hay zonas de diferente densidad en los datos). No asume ninguna distribución global.
LOF > 1.5 o 2: señal de anomalía. El umbral exacto depende del dominio. LOF = 1 significa densidad igual a sus vecinos = punto normal.

8 · Tendencia Central, Comparación de Distribuciones y EDA

Media (X̄)

  • Cuándo: distribución simétrica, sin outliers
  • Problema: muy sensible a outliers extremos (un valor de 120 infla toda la media)
  • Normal, Uniforme

Mediana

  • Cuándo: datos asimétricos, con outliers, ordinales
  • Ventaja: robusta, no se distorsiona por extremos
  • Lognormal → mediana = e^µ
  • Ingreso, tiempos de resolución

Moda

  • Cuándo: variables categóricas o distribuciones multimodales
  • Problema: sesga imputación hacia clase dominante

Hipótesis nula H₀ en regresión lineal: H₀: β_i = 0 (el coeficiente no es significativo, la variable no aporta al modelo). Si p < 0.05: el coeficiente es estadísticamente significativo.
Comparación de distribuciones: Superponer eCDF o histogramas de dos grupos. KS test para diferencia formal. Si las curvas se separan visualmente → diferencia real.

10 · Preguntas Prácticas Tipo Examen

❓ P1. Un analista compara tiempos de carga de dos apps (n=5000 c/u). Levene: p=0.000. t-Welch: t=0.05, p=0.293. Concluye "no hay diferencia". ¿Qué error cometió y qué harías tú?
Error: El t-test compara medias. Con datos asimétricos (latencias) la media es engañosa — App B puede tener mediana más baja pero picos extremos. El analista ignora que los SLAs se miden en percentiles (P95, P99), no en medias. Corrección: Mann-Whitney U, que compara rangos y es robusto a picos extremos. Un p-value de 0.293 solo dice que las medias no difieren, pero dice nada sobre las colas.
❓ P2. Tipo de tarjeta vs tipo de fraude. χ²=8.45, p=0.076. ¿Qué concluyes? La celda "Platino × Robo físico" tiene E_ij=2.1. ¿Qué problema hay?
Conclusión correcta: "Con α=0.05, no hay evidencia estadística suficiente para rechazar H₀ de independencia." (NUNCA "aceptamos H₀"). Problema E_ij=2.1: Viola el supuesto de χ² (todas E_ij ≥ 5). El estadístico se infla artificialmente porque al dividir por 2.1 cualquier diferencia (O-E) se amplifica. El p-value es no confiable. Solución: Fisher Exacta o combinar "Oro + Platino" en "Premium".
❓ P3. S = [2, 3, 2.5, 4, 3.1, 120]. Calcula el SE clásico. ¿Por qué es un desastre? ¿Qué harías?
SE clásico: s ≈ 47.8 (inflada por 120), SE = 47.8/√6 ≈ 19.5. El IC clásico daría algo como [Media ± 2×SE] = [22.4 ± 39] → límite inferior negativo: ¡tiempo negativo! Imposible. Solución: Bootstrap no paramétrico para la mediana. Mediana observada = 3.05h, que sí representa el grupo. El IC bootstrap excluye el valor 120 de la estimación de tendencia central.
❓ P4. R² de regresión auxiliar X₁ ~ X₂ + X₃ = 0.94. Calcula VIF₁ e interpreta qué le pasa al modelo.
VIF₁ = 1/(1-0.94) = 1/0.06 = 16.67 → Multicolinealidad severa (umbral crítico: VIF > 10). Al modelo: La columna X₁ de la matriz es casi combinación lineal de X₂ y X₃ → det(X'X) ≈ 0 → X'X es cuasi-singular → β̂ = (X'X)⁻¹X'y es inestable. Los errores estándar de todos los coeficientes explotan, los t-tests pierden significancia aunque las variables sí importen. Decisión: Eliminar X₁ (ya está contenida en las demás), o PCA, o Ridge.
❓ P5. Tienes horas de uso vs satisfacción (1-5 estrellas) con miles de empates en "4". ¿Pearson, Spearman o Kendall? Justifica.
Kendall τ-b. Razón: (1) Satisfacción es ordinal, no continua → Pearson viola supuesto de escala de intervalo. (2) La relación es monótona no lineal → Pearson subestima la asociación. (3) Miles de empates en "4" → Spearman asigna rangos promedio y se distorsiona. Kendall penaliza empates directamente en su denominador: τ_b = (C-D)/√[(C+D+E_X)(C+D+E_Y)], dando estimación más estable y con interpretación directa: probabilidad de concordancia menos discordancia.
❓ P6. El histograma de tiempos de resolución muestra pico alto a la izquierda y cola larga a la derecha. El Q-Q plot muestra desviación en las colas. El eCDF marca F̂(24)≈0.66 y F̂(40)≈0.88. El SLA exige 80% en ≤24h. ¿Qué distribución, cumple el SLA, y P(X>40h)?
Distribución: Gamma o Lognormal (soporte ≥0, asimetría positiva marcada). Normal es imposible (daría probabilidad a tiempos negativos). SLA: F̂(24) = 0.66 < 0.80 → NO se cumple, solo 66% en ≤24h, 14 puntos por debajo. Riesgo: P(X>40) = 1 - F̂(40) = 1 - 0.88 = 0.12 (12%). Con 1000 tickets/mes ≈ 120 tickets exceden 40h mensualmente.
❓ P7. ¿Qué prueba usas para cada caso? (a) Comparar ventas de 4 regiones, datos normales. (b) Tiempo entre pedidos vs tiempo de entrega, relación curva logarítmica. (c) Género del cliente vs canal de compra. (d) Latencia de dos servidores con distribución fuertemente asimétrica.
(a) ANOVA — 3+ grupos, datos normales. (b) Spearman o Kendall — relación monótona no lineal, variables continuas. (c) Chi-cuadrada (χ²) — dos variables categóricas, verificar E_ij ≥ 5. (d) Mann-Whitney U — datos asimétricos, comparar 2 grupos por rangos sin asumir distribución.
❓ P8. Diferencia entre bootstrap paramétrico y no paramétrico. ¿Cuándo falla cada uno?
No paramétrico: re-muestrea los datos crudos con reemplazo. Falla si n es muy pequeño (pocas combinaciones posibles) y si necesitas valores fuera del rango observado. Paramétrico (Monte Carlo): ajusta una distribución y muestrea de ella → puede generar valores nuevos, mejor con n muy pequeño. Falla si el modelo asumido es incorrecto: "basura entra, basura sale". Si la distribución asumida no es la real, todo el IC está sesgado.
Flujo Shapiro-Wilk: Normal → t-test/ANOVA | No normal → Mann-Whitney/Kruskal-Wallis
Flujo Levene: Varianzas iguales → t-Student | Varianzas distintas → Welch
Flujo correlación: Lineal continua → Pearson | Monótona/outliers → Spearman | Ordinal/empates → Kendall
